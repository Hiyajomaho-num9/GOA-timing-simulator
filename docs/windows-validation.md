# Windows 验证清单（0.4.8）

本清单由 Windows 实机验证完成。Linux 自动化测试不能替代 WebView、鼠标交互和桌面打包验证。

## 准备

1. 安装符合 `package.json` 要求的 Node.js / npm，运行 `npm ci` 和 `npm run check`。
2. 首次构建执行 `npx neu update`，然后运行 `npm run dist:win`。
3. 使用本地原始 XLSX 的副本，记录 Windows 版本、WebView 版本和本次提交号。

## 验收

| 检查 | 操作与预期 |
| --- | --- |
| 启动 / 导入 | 分别导入 MT9216 和 MT9603 文件，无白屏，识别到正确 GPO 与时序。 |
| 跨帧相位 | 选择重复周期不能整除帧行数的 GPO；在 120 frame 中放大后续帧，缩放前后边沿位置一致。 |
| 第二帧拖拽 | 使用 FCNT=1 的 entry，在其原帧内拖动；PCNT / LCNT 正确，FCNT 不变，脉冲不消失。拖出所属帧时拒绝修改。 |
| 非法寄存器 | PCNT / LCNT 输入负数、小数、空值、越界值；出现提示，原值与 patch 数量不变。 |
| 测量失效 | 测量一对真实边沿，然后禁用其中一个；显示“边沿已失效”，不保留旧测量数值。 |
| 起点 / 终点修正 | 分别选择能在帧内安全移动的起点和终点 entry；预览修正方向相反，确认后达到 Target。 |
| 测量编号 | 新建 T1/T2，删除 T1，再新增得到 T3；删除最新一条后编号仍不复用。 |
| Target 单位 | 设置 `30pcnt` 或 `1lcnt` 后改变 FPS / Htotal；Target 仍按原计数单位解释。时间单位 Target 保持物理时间。 |
| 导出回读 | 修改寄存器后导出；在 Excel 检查样式、数字格式、其他工作表，再重新导入核对波形。 |
| 无效文件 | 导入缺少 Panel/GPIO 或关键时序参数的 XLSX；明确报错，不显示伪造的默认时序。 |
| Worker / 旧 WebView | 切换 1/120 frame、多次修改参数和换文件；没有无限 loading、重复错误或残留旧波形。 |
| BIN / Compare | 保存并导入 Level Shifter BIN，使用 Compare memory，检查配置与原有功能仍正常。 |

发现问题时记录：原始参数、操作步骤、预期/实际、是否只在桌面版出现，以及可分享的最小复现文件。
